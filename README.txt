دعوتنامه عروسی امیرحسین و سوگل — نسخهٔ نهایی طراحی
====================================================

طراحی لوکس، اصیل و عاشقانه با پالت کرم/شامپاینی و فویل طلایی.

ویژگیها
--------
- تجربهٔ گشودن پاکت با مهر موم شکسته، بالهٔ سه‌بُعدی، نور متحرک دور قلب (GSAP)
- ذرات طلایی کنترل‌شده و افکت کرسر (cursor glow)
- تایپوگرافی دوزبانه: نستعلیق (Gulzar)، Vazirmatn، Cormorant، Great Vibes
- صفحهٔ اصلی سینمایی با قاب تزئینی، تقویم دی ۱۴۰۵ با روز ۲۰ برجسته (پویا)
- شمارش معکوس، تایملاین برنامهٔ شب، گالری چندقابی
- بخش تالار با لینک‌های نشان، بلد و Google Maps
- RSVP بدون سرور: پاسخ سه‌مرحله‌ای از طریق واتساپ + ذخیرهٔ محلی
- انتخاب موسیقی ۱.۵ ثانیه بعد از گشودن پاکت (بدون پخش خودکار)
- مودال موسیقی با focus trap، Escape و بازگشت فوکوس
- پشتیبانی کامل Reduced Motion؛ fallback بدون GSAP (بدون صفحهٔ سفید)
- واکنشگرا: ۳۲۰px تا ۱۴۴۰px + حالت landscape موبایل

ساختار فایلها
--------------
index.html              ساختار صفحه
css/tokens.css          توکنهای طراحی: رنگ، فونت، سایه، گرادیان فویل
css/base.css            ریست، تایپوگرافی پایه، دکمه‌ها، تزئینات
css/cover.css           پاکت، مهر، نامه و انیمیشن گشودن + حالت landscape
css/sections.css        بخشهای اصلی، مودال موسیقی و نقاط شکست
js/config.js            تمام محتوا و تنظیمات (تاریخ، رویدادها، RSVP)
js/cover.js             state machine و master timeline گشودن پاکت
js/app.js               شمارش معکوس، تقویم پویا، Revealها، موسیقی، RSVP
cdp-probe.cjs           ابزار تست خودکار (headless Edge via CDP)
start-server.bat        اجرای سرور محلی http://127.0.0.1:8080

شخصی‌سازی
----------
- تاریخ/برنامه/مکان: فقط js/config.js را ویرایش کنید (تنها Source of Truth).
- شماره واتساپ RSVP در همان فایل (بخش rsvp).
- تصاویر واقعی: فایلهای assets/images را با همان نام جایگزین کنید.
- موسیقی: assets/audio/ejaz.mp3 (~۹.۸MB، preload=none؛ در دسترس نبودن
  ابزار encode، بدون حذف). برای کاهش حجم با ffmpeg:
  ffmpeg -i ejaz.mp3 -b:a 96k -ar 44100 ejaz_small.mp3

انتشار
------
پروژه کاملاً استاتیک است؛ روی GitHub Pages، Netlify، Vercel یا هر هاست
قابل انتشار است. وابستگی خارجی فقط Google Fonts و CDN پکیج GSAP است.
اگر CDN در دسترس نباشد، پاکت با تایمینگ CSS باز می‌شود و سایت کامل کار
می‌کند (بدون Blank Page).

تست
---
node --check js/config.js && node --check js/cover.js && node --check js/app.js
پروژه باید روی HTTP server تست شود (start-server.bat)، نه file://.
